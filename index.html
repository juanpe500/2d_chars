2d_chars

procedural sprites

Tiny, dependency-free 2D character sprites for games. Drop in sprites.js and render a character with a single call — then use the built-in editor to design one: roll a random look, tweak every clothing and color option, spin through all 8 rotations, play the walk cycle, and export a config your game stores and replays with SpriteRenderer.drawAvatar().

★ Star on GitHub Try the editor ↓

Use it in your game

Only sprites.js ships to your game. The editor is optional — for the page where players create their character.

<!-- render characters (your game needs only this) -->
<script src="https://cdn.jsdelivr.net/gh/juanpe500/2d_chars@main/sprites.js"></script>

<script>
  // `avatar` is whatever the editor exported and your game stored:
  const avatar = JSON.parse(localStorage.getItem('avatar'));
  SpriteRenderer.drawAvatar(ctx, x, y, { avatar, direction: 'S' });
</script>

<!-- ...and the editor, only on your character-creation page -->
<script src="https://cdn.jsdelivr.net/gh/juanpe500/2d_chars@main/editor.js"></script>
<div id="app"></div>
<script>
  new CharacterBuilder('#app', {
    onChange(avatar) { localStorage.setItem('avatar', JSON.stringify(avatar)); }
  });
</script>
